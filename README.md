# stm32-demos

**STM32 外设驱动与中间件示例集合**。每个 demo 是一个最小可运行工程，只解决一个具体问题，便于复用和对照。

## 项目状态

🚧 持续更新中 —— 示例工程将按模块逐个提交。

## 示例清单

| 目录 | 外设 / 主题 | 内容 |
| --- | --- | --- |
| `01-gpio` | GPIO | 点灯、按键输入（轮询 / 外部中断） |
| `02-uart` | USART | 轮询 / 中断 / DMA + IDLE 不定长接收，printf 重定向 |
| `03-timer` | TIM | 定时中断、PWM 输出、输入捕获测频 |
| `04-adc` | ADC | 单通道/多通道采样、DMA 搬运、内部温度与参考电压 |
| `05-i2c` | I2C | 软件/硬件 I2C 读写 EEPROM 与传感器 |
| `06-spi` | SPI | SPI Flash、OLED 屏驱动 |
| `07-rtc` | RTC | 日历时钟、闹钟与备份寄存器 |
| `08-freertos` | FreeRTOS | 任务、队列、信号量、互斥量、软件定时器 |
| `09-lowpower` | 低功耗 | Sleep / Stop / Standby 模式与唤醒 |

## 目录结构

```

├── 01-gpio/
├── 02-uart/
├── ...
```

## 编译与运行

每个 demo 目录下含独立的工程文件，用 Keil / CubeIDE 直接打开对应工程即可编译下载。具体步骤随工程补充。
